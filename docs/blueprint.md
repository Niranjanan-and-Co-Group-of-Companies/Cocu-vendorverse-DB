# **App Name**: VendorVerse

## Core Features:

- Customer Portals: Personal and corporate portals with access to product catalogs, order placement, and requirement submissions.
- Vendor Portals: Separate portals for personal, corporate, and combined vendor types to manage products, bids, and orders.
- Admin Portal: Administrative interface for catalog, vendor, order, corporate, content, and financial management.
- Product Catalog: Browse and manage product listings with descriptions and pricing.
- Order Management: Track and manage customer and corporate orders through various stages of fulfillment.
- Bidding System: Allow vendors to submit bids on corporate requirements, managed via vendor and corporate portals.
- Landing Page and Login: Have the main landing page as Personal, and on login/ sign up only the customer can get in to the corporate customer landing page.

## Style Guidelines:

- Primary color: Blue (#4285F4), conveying trust and reliability for both customers and vendors.
- Accent color: Orange (#FFA000) for call-to-action buttons and important notifications.
- Background color: Light gray (#F5F5F5) provides a clean and neutral backdrop to ensure readability and focus on content.
- Body font: 'Inter', a sans-serif font for clear and modern readability. Headline font: 'Space Grotesk', sans-serif, for headlines to give the site a clean futuristic aesthetic.
- Consistent use of minimalist icons to represent different product categories and portal sections, aiding intuitive navigation.
- Clean, grid-based layout to organize information effectively across all portals, ensuring responsiveness on different devices.
- Subtle transitions and feedback animations on user interactions (e.g., button clicks, form submissions) to enhance the user experience.
